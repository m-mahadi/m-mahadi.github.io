Typi

Typi is an open source typewriter simulator and typewriter writing app for Windows and Obsidian. It is built for focused writing: no paste, no dumping, just typing your own words into Markdown notes.

Why it exists

A lot of writing apps make it easy to collect text. Typi is typewriter software for the opposite moment: when you want to sit down, write slowly, and actually produce a note yourself. It works as typewriter simulator software with a typewriter-style interface, local key sounds, and simple Markdown files so the writing stays yours and the files stay portable.

What Typi does

  • Blocks paste and drag-drop input so the app stays a place for writing from scratch.
  • Autosaves the current sheet into a local Typi vault while you write.
  • Saves notes as Markdown in Typi Notes/.
  • Opens the active note directly in Obsidian.
  • Lets you choose where your vault lives, including a local drive outside OneDrive.
  • Works even without Obsidian because the files are plain Markdown.
